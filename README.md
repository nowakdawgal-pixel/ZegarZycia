# Zegar Życia — Android

Nowy, niezależny projekt aplikacji wspierającej ograniczanie i porzucanie nałogów. Nie zastępuje aplikacji Zegar Trzeźwości.

## Funkcje prototypu
- ekran pierwszego uruchomienia i wybór wielu kategorii
- liczniki abstynencji/nawyków i wybór daty startu
- własne kategorie
- szacowanie niewydanych pieniędzy i wspólny cel skarbonki
- dziennik nastroju, głodu i notatek
- ekran wsparcia z planem na trudną chwilę i osobistymi powodami
- postępy i kamienie milowe
- ustawienia kategorii i lokalne przechowywanie danych

Dane są zapisywane lokalnie w SharedPreferences. Nie ma jeszcze kopii zapasowej, powiadomień, AdMob ani eksportu. Przed publikacją konieczne są testy na urządzeniu, weryfikacja dostępności i polityki prywatności oraz konfiguracja reklam, jeśli mają zostać dodane.

## Budowanie
Projekt wymaga Android SDK 35, JDK 17 i Gradle 8.9+ (zalecany Gradle zgodny z Android Gradle Plugin 8.7.3).
